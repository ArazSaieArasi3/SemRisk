# Diagrams and bounded Explorer

> Ontology documentation candidate 0.2.0-rc.4. Source snapshot `67247f13ba5d0c7d32163f2b3e848af15067d92e`. Not a scholarly release or independent domain validation. No manuscript is included.

[Browse all 15 canonical conceptual views](https://arazsaiearasi3.github.io/SemRisk/ontology/0.2.0-rc.4/docs-20261006/diagrams.html) or [open the rc.4 WebVOWL explorer](https://arazsaiearasi3.github.io/SemRisk/ontology/0.2.0-rc.4/docs-20261006/explorer/index.html).

The conceptual views retain their original source identity and limitations. The complete original atlas fails 170 mm print readability; native-editor and complete OntoUML acceptance remain open. No unpublished print companion is included.

The existing WebVOWL 1.1.7 renderer is reused with a bounded asserted-source adapter. It is not OntoUML. The graph includes 46 local classes and 24 object properties with explicit named endpoint pairs. The remaining 26 object properties and all eight datatype properties stay in the exhaustive searchable term index; no missing endpoint is invented. Enumeration closure, disjointness visualization, anonymous expressions, metatypes and complete imported semantics are not represented by graph layout.

Use the graph selector for Core, Enterprise, Method or assessment-context. Governance, Pharma and Mappings remain accessible through index-only links where no graphable pair exists. Search by stable ID or IRI in the formal index. Use zoom, center and details controls; keyboard focus is visible. Uploads, remote conversion, arbitrary URL loading and editing are disabled in this read-only bundle.

Graphical readability remains partial, especially in dense or narrow-screen views; use zoom/pan or the complete term index for readable definitions. Independent engineering-reader and academic/domain-reader tasks have not been executed. Browser automation is technical preflight, not participant evidence. Runtime notices and gUFO attribution are linked in the Explorer and source page.
