# Semantic architecture

> **Status:** P1-R2 candidate / 0.1.0-rc.1. These are source-controlled Wiki drafts. Final scholarly release, public access and citation remain pending #55/#56. The ontology files and governed evidence linked below are authoritative.

Core owns the generic risk pattern. Enterprise, Method, Governance and Pharma modules add bounded semantics; Mappings records external-owner references. Objective, Capability and Business Process are not silently minted as generic SemRisk Core classes. CM-PharmE ownership is used only where an exact profile concept exists. The PostgreSQL projection is an application representation.

Selected IDs: Risk `SR-CPT-001`; scenario `SR-CPT-006`; event `SR-CPT-007`; register entry `SR-CPT-033`; situational Risk State `SR-CPT-035`; workflow state `SR-CPT-036`. These are selected distinctions, not a complete class diagram.

For the **full local declaration set**, use the [zoomable 76-ID ontology atlas](https://github.com/ArazSaieArasi3/SemRisk/blob/2786302451c948106ec0df413d771ef0dff712f2/docs/ontology/diagrams/p1-r2-local-ontology-atlas-v0.1.svg) and its [37-property asserted relation map](https://github.com/ArazSaieArasi3/SemRisk/blob/2786302451c948106ec0df413d771ef0dff712f2/docs/ontology/diagrams/p1-r2-local-relations-v0.1.svg). Their [scope and limits](https://github.com/ArazSaieArasi3/SemRisk/blob/2786302451c948106ec0df413d771ef0dff712f2/docs/ontology/diagrams/README.md) separate locally declared classes/properties/markers from imported gUFO, SHACL, SQL and inferred closure. Labels resembling stereotypes indicate actual RDF declaration types, not asserted OntoUML stereotypes; no cardinality is invented.
