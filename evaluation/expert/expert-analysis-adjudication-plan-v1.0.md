# Expert Review Analysis and Adjudication Plan v1.0

This plan is frozen before reviewer responses are interpreted.

1. Preserve one raw response row per reviewer×item.
2. Validate eligibility and item applicability before analysis; do not convert blanks to acceptance.
3. Report A/B/C/D/NA counts and assessed denominator for every item.
4. Preserve C/D rationales individually in the finding register.
5. Do not compute a canonical average score.
6. Summarize expertise coverage and independence separately from judgments.
7. Classify findings Critical/High/Medium/Low using the frozen #51 protocol.
8. Any Critical/High semantic finding blocks expert-validation PASS for the affected item/claim until remediation and required re-review.
9. If material model changes occur, rerun affected formal/CQ/application regression and bind the new candidate before re-review.
10. Only after all open Critical/High findings are disposed may #30 produce a bounded E5 conclusion.

Optional agreement statistics are secondary and only considered when at least four eligible reviewers assessed the same ordinal item and the statistic is defensible for the response scale/sample. Raw distributions remain authoritative.
