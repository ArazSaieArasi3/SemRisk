# SemRisk candidate 0.2.0-rc.2

Successor to the frozen 0.2.0-rc.1 implementation candidate, not a stable/publication release. Seven modules remain: six inherited modules plus the operational context profile. The declared delta is four definition clarifications, the broad RiskOwner metatype correction from Role to RoleMixin, and one opt-in GroundedRiskResponsibility helper. No class/instance IRI is renamed. The metatype change is semantic and is not claimed equivalent to the old typing.

[Manifest](manifest.json) binds source hashes and offline dependencies. [Decision and coverage audit](../../../foundational/revision-2026-10-05/decisions.md) covers all 47 concepts and 38 relation decisions. [Formal protocol](../../../evaluation/foundational/2026-10-05/formal-protocol.md) defines positive, negative, entailment and countermodel probes. Test results and actual CI records are under `evaluation/foundational/2026-10-05/`.

The new data shape is opt-in and requires explicit distinct endurant participants. OWL consistency alone can admit unnamed witnesses and is not evidence of complete responsibility data. Existing numeric/temporal SHACL, V007 SQL and owner queries are reused unchanged. The stricter named-counterpart profile is not yet projected into SQL.

Reproduce from repository root:
```bash
python -m pip install -r tools/requirements-qualified-context.txt
python tools/build_foundational_candidate.py --check --assemble
python tools/check_foundational_revision.py --write
```
The workflow adds actual ROBOT/HermiT runs and retains input/output evidence. Remaining scenario type-level, information identity and workflow representation choices must be settled before the full editable OntoUML is accepted. No empirical case or expert response is generated by these synthetic tests.
