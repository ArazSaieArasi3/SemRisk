# Assessment Context Vocabulary Policy v1.0

**Owner:** Issue #82

Paper 1 directly models:
- Inherent Risk Assessment Result — pre-treatment/pre-control assessment context;
- Residual Risk Assessment Result — post-treatment/control assessment context.

Common ERM labels such as **gross**, **current**, **target**, **desired**, **controlled**, or **net** are framework/method/profile terms. They are not universal SemRisk Risk identities or automatic synonyms.

Prohibited automatic equations include:
- current = residual;
- gross = inherent;
- target = tolerance;
- target = residual;
- net = residual.

Any such mapping requires an explicit source/framework/method locator plus a mapping relation (exact/close/broader/narrower/related or local profile rule).

No additional timeless Risk subclasses are introduced by this policy.
