2. **COVER's Value/Risk/Vulnerability/RiskEvent reference semantics** — referenced/aligned; not renamed as new SemRisk inventions.
3. **ROSE SecurityMechanism, security Vulnerability, control/protection-event semantics** — security/profile prior art; SemRisk only defines a cross-domain operational pattern where justified.
4. **Generic provenance vocabulary** — prefer PROV-O reuse/alignment.
5. **Pharmaceutical ecosystem entities** — CM-PharmE remains canonical owner.
6. **Biopharma QRM vocabulary already owned by IOF Biopharma** — align/reference where materially overlapping.
7. **Medical-device Hazard/Harm/Safe Design Argument semantics** — RISKMAN/ISO 14971 profile territory.
8. **Pharmacovigilance Signal/report semantics** — OpenPVSignal/PV profile prior art.
9. **AI risk vocabulary** — AIRO/profile territory, outside P1.
10. **Enterprise Objective/Capability/Process taxonomies** — externally owned; SemRisk owns only risk-linkage semantics.

SemRisk's candidate contribution is therefore not a renamed copy of these constructs. It is the governed operational semantic architecture that distinguishes risk phenomenon/event/scenario from information artifacts, assessment activity/results/states/workflow/evidence/treatment/responsibility and federates external domain owners.
