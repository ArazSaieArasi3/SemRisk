The two large SVGs are repository reference views intended for zoom and search, not a one-column IEEE figure. The labels `«OWL Class»`, `«Object Property»` and `«SKOS marker»` state RDF declaration type; they are **not** inferred OntoUML stereotypes. Arrows in the relation map denote the asserted domain→property→range signature, not causal/data flow or a validated cardinality. OWL domain/range can infer types and does not function like a SQL foreign key or SHACL completeness check. No explicit cardinality is inferred where source does not assert one.

The denominator excludes imported gUFO declarations and axioms, external-owner semantics, SHACL shapes, instance/test graphs, SQL tables and inferred OWL closure. The full asserted graph and imported source list are in [the generated reference](../generated/p1-r2-generated-reference.md).
