# Control Mechanism vs Assurance Boundary v1.0

**Owner:** Issue #81

SemRisk Paper 1 distinguishes Risk Treatment Strategy, Plan, Activity and Control Mechanism.

A Control Mechanism instance or an activity using a control does **not** entail:
- design adequacy;
- implementation completeness;
- operating effectiveness;
- assurance/test success;
- reduced likelihood/impact;
- reduced residual risk.

Control testing, control-design assessment, operating-effectiveness assessment, assurance activity, assurance evidence and assurance conclusion are recognized as future Governance/Assurance profile capabilities.

The synthetic Paper-1 E2E control exists solely to exercise representation and projection. It is not empirical evidence of control effectiveness.
